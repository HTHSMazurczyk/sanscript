Lesson 3 - Syllables


Welcome to lesson 3! I hope you did the practice for the previous two lessons because today we are putting them together to learn how to pronounce words. This requires the pronunciations from lesson 1 and the ability to identify syllables from lesson 2. If you think you need more practice, please either read the lessons again or do more practice and then come back when you are ready.


Ok, now that you are ready to start pronouncing words, let's start with some basics. You already know how the syllable system works, so I trust that you will be able to do that. The main challenge here is going to be able to properly pronounce each syllable and string them together into a complete word. Let’s use an example word that we previously looked at.


Varṣabhogyeṇa

Since we looked at this last time, we can just separate it into its syllables to look like this:

Var - ṣa - bhog - ye - ṇa


Now comes the hard part. Go one by one and try to pronounce each syllable one by one. You can use the tables of letters in the index or lesson one to remind yourself how the letter is pronounced. Once you sound it out, play the audio above each syllable to check your understanding. Come back once you have pronounced each syllable correctly.

Now that you have done that, put the syllables together. It’s ok if it takes you some time to do so; it’s natural to struggle. Take some time now to put together the sounds and string them into a complete, uninterrupted word. When you finish up with that, you can click the audio for the word below to hear the entire word being pronounced.

That was a pretty tough word; let's be honest here. Let's try one with another smaller word. Here it is. Again, try to separate it into syllables, and I will provide the answer right after for your reference. Try this out:


Saṃjaya
