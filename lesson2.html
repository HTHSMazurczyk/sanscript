Lesson 2 - Syllables


Welcome to lesson two! Now that you know the letters, it’s time to start with syllables. Syllables in Sanskrit are pretty similar to syllables in English. To start, each syllable has only one vowel in it. To extend this, a syllable cannot start with a vowel whatsoever. However, this poses a problem. When trying to pronounce words with multiple consonants between them. Take the example below.

Kaścit


Woah! It’s an entire word! But we can separate it into syllables using the two vowels here. However, there are two consonants between the vowels! How do we know which consonant is part of which syllable? Well, that’s where our third rule comes in. This rule states that we want to make each syllable as big as possible from left to right. If that sounds confusing, then let's show a more visual representation. Say that we separate the word into two syllables like this:

Ka - ścit


This looks correct by our first two rules. Each vowel shows the distinction between the syllables. But we have to follow the third rule, which states that we need to make the syllables from left to right as big as possible. If we remove the ś from the second syllable and place it at the end of the first syllable, will all rules be followed? I’ll show you the new syllables, and you think about whether this is valid or not.
Remember: each syllable has exactly one vowel and must start with a consonant

Kaś - cit


If you said that this is valid, then you are correct! Both rules have been followed. If you didn’t get that right, then let's go over this one more time. The first rule states that each syllable has exactly one vowel. This rule is followed here, as the a and i are in separate syllables, noted by the hyphen. Next, they must start with a consonant, which is followed. The a starts with a K, and the i starts with a c. The main area of confusion is with the movement of the ś. Why can we do this? To better understand this, think of it like this: the ś is not needed for the first syllable for it to be valid. The same is true for the second syllable. The ś is free-floating, but we can’t leave it as its own syllable; that would break our one vowel per syllable rule! Instead, you append it to the end of the previous syllable. We have to make each syllable as large as possible! If we try to extend the first syllable further to include the c, it would break our second rule because then there would be no consonant to shield the vowel.
I hope that made at least a little bit of sense to you. In short, we have defined three rules of Sanskrit syllables:

  1. There is exactly one vowel in each syllable
  2. Vowels cannot be located at the start of a syllable. They must always start with a consonant
  3. Each syllable must be as large as possible without interfering with the next syllable (mainly used for free-hanging consonants)
 Great! Let’s do a little bit of practice before we move on to the last topic. I’ll give you a word and you try to separate it into its syllables. Once you do that, check your work with the answer that will be provided below the word. It might be best for you if you have a list of the vowels like in the previous lesson, as some English consonants are vowels in IAST. You got that? Let's start.

Bhartuḥ


This one is similar to the previous one. Our two vowels are “a” and “u”. Next, we add the consonant directly to the right of them to start the syllable, so “Bh” is added to “a” to make “Bha,” and “t” is added to “u” to make “tu”. Finally, we add any consonants that are free-floating to the ends of the previous syllable. So the “r” snaps on to the previous syllable to make “Bhar,” and “ḥ” appends to the end of the last syllable, creating “tuḥ”. So, the word split into syllables should be:

Bhar - tuḥ


Good job if you got that right! A little shortcut you can use if this was a little too easy is to just look for vowels, skip the consonant before it, and demarcate a syllable. Using this method, the above answer could be reached by identifying “a” and “u” as vowels. Skip over the preceding consonant, and that’s your syllable! Pretty cool, right? Let's try this method on a much longer word:


Varṣabhogyeṇa


This looks challenging, but remember the shortcut. Find vowels, skip over the consonant before them, and there is your syllable. Using this rule, we can find the correct syllable marks, as seen below.

Var - ṣa - bhog - ye - ṇa


So that brings us to the end of our lesson. I hope you were able to understand this lesson. Again, try to do some practice with this lesson so that you are comfortable creating syllables. This is going to be the deepest that we go with grammar; the rest of the lesson will focus solely on pronunciation. See you next lesson!
